# Archivo Gohan

Sitio de tres páginas construido con HTML y CSS a partir de las ilustraciones de `resources/`.

- `index.html`: portada y recorrido del proyecto.
- `neighborhood.html`: galería visual de ocho imágenes.
- `parks.html`: página editorial sobre práctica y entrenamiento.
- `css/style.css`: navegación, cuadrículas, diseños flexibles, estados interactivos y estilos adaptables.

Abre `index.html` en un navegador para recorrer el sitio.
